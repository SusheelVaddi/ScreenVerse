# ScreenVerse

ScreenVerse is a unified entertainment discovery and exploration platform built for fans of movies, TV/web series, anime, cartoons, animation, characters, people, and franchises.

---

## 📌 Project Overview

ScreenVerse is designed to simplify how users discover entertainment content and explore the deep connections between titles, actors, voice actors, characters, franchises, universes, and watch orders.

### Current Features (Step 1 — Foundation)
- **Cinematic Dark UI Layout**: Responsive, modern, dark-first design built with Next.js and Tailwind CSS.
- **Universal Header & Footer**: Navigation shell and status indicators.
- **Hero & Search Bar Placeholder**: Visual search component ready for API integration in Step 4.
- **Category Foundation Sections**: Visual layout placeholders for Movies, TV & Web Series, Anime, Animation, Popular People, and Franchises.

---

| Technology | Purpose |
| :--- | :--- |

## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18.x or later recommended)
- npm (installed with Node.js)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

### 3. View in Browser
Open your browser and navigate to:
```
http://localhost:3000
```

## 🗺️ Planned Future Features (Roadmap)

The following features are planned for future build steps:
- **Universal Search & API Integration**: Real-time multi-entity search for movies, series, anime, characters, people, and franchises.
- **Detailed Entity Pages**: Dedicated exploration pages for movies, TV series, anime (with arc & OVA support), people, and characters.
- **Franchise & Universe Timelines**: Interactive watch order guides (chronological vs release order).
- **Personal Watch Tracker & Lists**: User accounts, watchlists, watched history, and ratings.
- **Kids Mode**: Safe, age-appropriate visual discovery mode.
- **AI Assistant**: Natural-language query parsing and personalized recommendations grounded in real data.
